Политика конфиденциальности DKC_KP

Дата редакции: 30.10.2026

Какой доступ запрашивается

Приложение запрашивает только разрешение Google Drive drive.file. Оно даёт доступ исключительно к файлам, которые создало само приложение. К остальным файлам Google Диска, почте, контактам и другим данным аккаунта приложение доступа не имеет.

Какие данные обрабатываются

Приложение создаёт и изменяет таблицы расчёта коммерческих предложений: позиции, количества, цены, скидки, стоимость работ и примечания. Ссылки на эти таблицы сохраняются во внутренней системе учёта запросов.

Хранение и передача

Ключ доступа хранится на закрытом сервере владельца приложения и не передаётся третьим лицам. Данные из Google не продаются, не используются для рекламы и не передаются другим сервисам. Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions. Созданные таблицы остаются на Google Диске владельца, их можно удалить обычным способом.

Контакты

Вопросы по обработке данных — по адресу службы поддержки, указанному на экране согласия Google.
